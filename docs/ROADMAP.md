# Completion criteria

The next milestone is a small working MCP assessment, using the already demonstrated local model connection.

1. Expose one fixed local check as a genuine MCP tool. Show initialisation, tools/list and tools/call.
2. Enforce the target and permitted parameters in the tool server. Test a rejected out-of-scope request.
3. Save timestamped tool output and its request context. Preserve errors and partial results.
4. Connect one model-selected follow-up to that tool and retain the selection trace.
5. Validate one of the ten existing case IDs with its proper baseline and confirmation threshold.
6. Draft and review one evidence-linked report entry before scaling to the remaining cases.

The original ten IDs remain the project catalogue. They are not proof that ten weaknesses were found. Browser and two-account checks require their own evidence.

Optional goals are a single reversible remediation with a repeated test and health control, a second model comparison and a simple measured comparison against a fixed workflow. Keep these separate from demonstrated achievements until their evidence is committed.
